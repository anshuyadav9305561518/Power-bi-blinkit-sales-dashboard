# Blinkit Sales Dashboard – Power BI

## Project Overview

This project is an interactive Blinkit Sales Dashboard created using Microsoft Power BI. It analyzes sales performance and provides useful business insights through interactive visualizations.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning
* Data Analysis
* Data Visualization

## Key Features

* Sales performance analysis
* Product and category analysis
* Outlet/store performance analysis
* Interactive charts and visualizations
* KPI cards
* Filters and slicers
* Business insights

## Project File

* `blinkit.pbix` – Power BI dashboard project file

## Objective

The objective of this project is to analyze Blinkit sales data and create an interactive dashboard to understand sales performance, product categories, and outlet-level information.
